# Archive — historical task records

> **FROZEN POINT-IN-TIME RECORDS.** Everything in this directory is kept for
> provenance only. It is **not** current guidance. Some of it describes
> behaviour that has since been superseded — for example a removed BGM audio
> system, pre-2026-11 availability counts, and pre-redesign layouts.
>
> Relative links inside these files (such as `../app/...` or `../lib/...`) were
> written when the files sat at the `docs/` root. They may no longer resolve
> from `archive/`. That is expected and is intentionally not fixed here —
> repairing historical records would rewrite the evidence they preserve.

Current documentation lives one level up, starting at
[`../README.md`](../README.md).
